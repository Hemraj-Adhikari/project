#  My Portfolio in C Language

This is my personal portfolio project developed using the C programming language.  
The main purpose of this project is to showcase my basic programming skills and personal information using a simple console-based application.

##  Features

- Displays personal introduction
- Shows skills (C, C++, Java, Python, etc.)
- Menu-based navigation system
- Contact information section
- Simple console user interface

##  Technologies Used

- C Programming Language
- GCC Compiler
- Command Line Interface (CLI)
